# hargarten.net

Statische Firmenseite von Benjamin Hargarten – Softwareentwicklung (Startseite, Impressum, Datenschutz) mit einer Übersicht der Apps, ohne Build-Schritt und ohne externe Ressourcen. Gehostet als GitHub Pages User-Site unter infman-sudo.github.io (`.nojekyll` schaltet die Jekyll-Verarbeitung ab). Die Seite läuft unter https://hargarten.net, das DNS liegt bei Host Europe (AutoDNS).
